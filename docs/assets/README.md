# Bilder und Zeichen

| Datei | Wofür |
|-------|-------|
| `logbot-icon.png` | Das LogBot-Zeichen, 192×192. Steht in der Haupt-README und als `apple-touch-icon`. |
| `logbot-icon-round.png` | Runde Fassung, 192×192. Dient als Standard-Favicon. |

Beide stammen aus der [Android-App](https://github.com/Phydran6/Logbot-Android-App)
(`app/src/main/res/mipmap-xxxhdpi/`) — Server und App tragen damit dasselbe
Zeichen.

Eingebunden sind sie über `frontend/public/`. Wer ein eigenes Logo oder Favicon
unter *Einstellungen → Erscheinungsbild* hochlädt, überschreibt sie zur
Laufzeit; die Dateien hier bleiben die Rückfallebene.
